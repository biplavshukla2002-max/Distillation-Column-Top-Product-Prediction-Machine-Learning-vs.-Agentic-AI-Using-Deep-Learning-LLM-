# # Distillation Column Top-Product Prediction

## Project Overview

This project develops an AI-based prediction framework for a
benzene-toluene binary distillation column simulated using DWSIM.

The study compares conventional Machine Learning models with a
Deep Learning-based Agentic AI approach.

## Project Workflow

DWSIM Simulation
        ↓
496-Point Dataset
        ↓
Data Analysis
        ↓
Machine Learning Model Comparison
        ↓
Random Forest Prediction
        ↓
Deep Learning Model
        ↓
Agentic AI
        ↓
Gemini LLM Recommendations

## Technologies Used

- DWSIM
- Python
- Pandas
- NumPy
- Scikit-learn
- TensorFlow/Keras
- Google Gemini API
- DWSIM VERSION 9.O

## Dataset

The dataset contains 496 DWSIM simulation points generated by
varying the feed molar flow rate.

## Machine Learning

Multiple regression models were tested and their prediction
performance was compared using R², MAE, MSE and RMSE.

## Deep Learning

A TensorFlow/Keras regression model was developed for
distillation-column output prediction.

## Agentic AI

The trained Deep Learning model is integrated into an
Agentic AI workflow. The agent accepts process input,
generates a prediction and provides process-related
recommendations using an LLM.

## Project Structure
